# Dynamic Content Creation Lab

A JavaScript application that demonstrates how to dynamically create, update, and remove HTML elements using the Document Object Model (DOM). This project focuses on interactive web development by allowing users to add content to the page without refreshing the browser.

---

## Overview

This lab demonstrates core JavaScript DOM manipulation concepts by allowing users to dynamically create content through user interactions. Elements are generated entirely with JavaScript, making the page interactive and responsive.

---

## Features

- Dynamically create HTML elements
- Add new content using user input
- Remove items from the page
- Update existing elements
- Responsive layout using Bootstrap
- Clean and organized user interface
- Event-driven JavaScript functionality

---

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript (ES6)
- DOM Manipulation

## 🎯 Learning Objectives

This project demonstrates how to:

- Select DOM elements
- Create elements with `document.createElement()`
- Append elements to the DOM
- Remove elements dynamically
- Modify element content and attributes
- Handle user events
- Organize JavaScript into reusable functions

## How to Run

1. Clone the repository.

```bash
git clone https://github.com/yourusername/dynamic-content-creation.git
```

2. Navigate into the project folder.

```bash
cd dynamic-content-creation
```

3. Open `index.html` in your preferred web browser.

No additional installation or dependencies are required.
